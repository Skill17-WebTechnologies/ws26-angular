# Angular 21.1.4 — WSC2026 minimal app

```bash
docker compose up --build
```

Open **http://localhost:4200** — a minimal Angular app (scaffolded with Angular CLI 21.1.4),
with a signal-based counter. Pinned: Node 24.1.0 / npm 11.5.0, Angular 21.1.4.

First start compiles the app, so give it a few seconds.
